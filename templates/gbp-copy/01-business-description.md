# 비즈니스 설명 750자 — 채워서 그대로 붙여넣기

## 규칙
- **첫 100자**에 Tier S 키워드 + 도시명 (검색결과에서 잘리는 지점)
- 키워드 나열 금지 — 사람이 읽는 문장이어야 합니다
- **가격·프로모션·URL·이메일은 넣지 않습니다** (정책 위반으로 반려됩니다)
- 750자 안에서 한/영을 자연스럽게 섞어도 됩니다. 뒤에 번역을 통째로 덧붙이지는 마세요

## 골격

```
[① 도시명]에 있는 [② 업종]인 [③ 상호]는 [④ 우리만의 차별점]을 제공합니다.
[⑤ 주력 상품·서비스 3가지]를 중심으로 [⑥ 이용 방식: 매장/포장/배달/예약]을 운영합니다.
[⑦ 부가 업종 언급 — 복합 매장이면 여기서 한 문장]
[⑧ 편의 정보: 주차, 응대 언어, 단체·예약 가능 여부]
```

## 채우기

| 자리 | 내가 넣을 것 | 어디서 가져오나 |
|---|---|---|
| ① 도시명 | | 프로필 `city` |
| ② 업종 | | Tier S 키워드의 업종어 |
| ③ 상호 | | 간판과 동일 |
| ④ 차별점 | | 남이 못 쓰는 사실 한 가지 (직접 담근다 / 20년 경력 / 원산지) |
| ⑤ 상품 3가지 | | 키워드맵 Tier S·A |
| ⑥ 이용 방식 | | 포장·배달·예약 여부 |
| ⑦ 부가 업종 | | 복합 매장일 때만 |
| ⑧ 편의 정보 | | 주차, 한국어 응대 등 |

## 작성 예시 (음식+리테일 복합)

> 포트무디에 있는 한식당 OO식당은 매일 직접 담그는 김치와 24시간 우린 사골 육수로 정통 한식을 제공합니다. 김치찌개, 불고기, 한식 BBQ를 중심으로 점심 특선과 포장·배달을 운영하며, 4인 이상 단체 예약과 케이터링도 가능합니다. 매장 한편에서는 한국 라면, 과자, 김치 등 한국 식료품도 함께 판매하고 있어 식사 후 장을 보실 수 있습니다. 건물 앞 무료 주차가 가능하며 영어와 한국어 모두 응대해 드립니다.

- [ ] 첫 문장에 도시명 + 업종 키워드가 있는가
- [ ] 750자 이내인가
- [ ] 가격·URL·이메일이 없는가
- [ ] 소리 내어 읽었을 때 어색하지 않은가 (어색하면 키워드가 과한 것)
