# 리뷰 요청·답글 문구 — 복사해서 쓰기

## ⚠️ 먼저: 절대 하면 안 되는 것
할인·사은품·이벤트 응모 등 **대가를 걸고 리뷰를 요청하면 구글 정책 위반**입니다. 리뷰가 일괄 삭제되고 프로필 신뢰도가 떨어집니다. "리뷰 남겨주시면 음료 서비스" 같은 문구는 쓰지 마세요.

---

## 1. 리뷰 요청

**QR 스탠드 (계산대 비치)**
```
오늘 어떠셨나요?
구글 리뷰 한 줄이 저희에게 큰 힘이 됩니다 🙏
(QR) 30초면 됩니다

How was your visit?
A quick Google review means a lot to us 🙏
```

**문자/카톡 (서비스 완료 24시간 내, 1회만)**
```
안녕하세요, [상호]입니다.
오늘 방문해 주셔서 감사합니다. 괜찮으셨다면 구글 리뷰로
짧게 남겨주실 수 있을까요? 링크: [리뷰 링크]
```

**대면 요청 (가장 전환율이 높음)**
> "혹시 괜찮으셨으면 구글에 한 줄 남겨주실 수 있을까요? 저희 같은 작은 가게엔 정말 큰 도움이 돼요."

---

## 2. 답글 — 100% 답니다

### 4~5점 (24시간 내)
```
[고객명]님, [메뉴/서비스명] 맛있게(만족스럽게) 드셨다니 기쁩니다!
다음에 오시면 [다른 메뉴]도 추천드릴게요. [도시명]에서 또 뵙겠습니다 :)
```
> 포인트: **감사 + 상품명(키워드) 언급 + 재방문 유도**. 상품명이 리뷰 답글에 들어가면 관련성 신호가 됩니다.

### 3점
```
소중한 의견 감사합니다. 말씀 주신 [지적 사항]은 저희도 개선이 필요하다고
느끼고 있어 [구체적 조치]를 진행하고 있습니다. 다음에 오시면 달라진 모습
보여드리겠습니다.
```

### 1~2점 (24시간 내, 방어하지 말 것)
```
불편을 드려 죄송합니다. 말씀 주신 [문제]는 [구체적 조치]로 개선하고 있습니다.
괜찮으시면 [전화번호]로 연락 주시면 직접 확인하고 싶습니다.
```
> **다른 예비 고객이 이 답글을 읽습니다.** 반박·변명은 새 고객을 잃습니다. 사과 → 조치 → 오프라인 연락처, 이 순서만 지키면 낮은 평점도 신뢰 신호가 됩니다.

### 영어 답글
```
Thank you so much, [name]! We're glad you enjoyed the [dish/service].
Next time, try our [other item] — hope to see you again in [City]!
```

## 3. 페이스 관리
| 항목 | 기준 |
|---|---|
| 리뷰 확보 속도 | **주 2~3개.** 하루에 몰리면 스팸 필터에 걸립니다 |
| 답글률 | 100% |
| 답글 속도 | 긍정 24~48시간, 부정 **24시간 내** |
| 리뷰 공백 | 3개월 이상 새 리뷰가 없으면 감점 신호 |
| 언어 | 한국어·영어 리뷰가 **둘 다** 있어야 양쪽 검색에 잡힙니다 |
