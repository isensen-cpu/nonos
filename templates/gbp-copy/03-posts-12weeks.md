# 게시물 12주 캘린더 — 주 1회, 15분

## 매 게시물 공통 규칙
- **사진 1장 필수** (없는 게시물은 노출이 거의 안 됩니다)
- **CTA 버튼 반드시 설정** — 자세히 보기 / 전화 / 경로 / 온라인 주문 / 예약 중 하나
- 첫 문장에 그 주의 키워드 1개 (키워드맵 Tier B에서 순서대로)
- 길이는 150~300자. 길게 쓰지 않습니다

---

## 12주 로테이션

| 주 | 주제 | 첫 문장 골격 | 사진 | CTA |

> 12주가 끝나면 1주로 돌아가되 **사진과 문구는 새로 씁니다.** 같은 내용을 복사해 올리면 중복으로 처리됩니다.

## 작성 예시

**1주차 — 대표 메뉴**
```
포트무디에서 김치찌개를 찾으신다면, 매일 아침 직접 담근 김치로 끓입니다.

3년 묵은 김치와 24시간 우린 사골 육수만 씁니다. 점심시간에는 공기밥과
계란찜이 함께 나갑니다. 포장도 가능합니다.

[사진: 김치찌개 클로즈업]  [버튼: 경로]
```

**9주차 — 인접 지역**
```
코퀴틀람에서 차로 10분, 주차는 건물 앞 무료입니다.

세인트존스 스트리트 대로변이라 찾기 쉽습니다. 저녁 시간대에는 옆
공영주차장도 이용하실 수 있습니다.

[사진: 야간 외관 + 간판]  [버튼: 경로]
```
