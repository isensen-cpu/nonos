# Q&A 씨앗 5~8개 — 사장이 직접 올린다

고객이 질문할 때까지 기다리지 않습니다. **사장이 직접 질문을 등록하고 직접 답변하는 것은 구글 정책상 허용**됩니다.
질문·답변 양쪽에 Tier B 키워드를 자연스럽게 넣으면 추가 매칭 표면이 생깁니다.

## 필수 5개 (업종 무관)

```
Q: [도시명] 매장에 주차 가능한가요?
A: 네, 건물 앞 무료 주차 [n]대가 가능합니다. 저녁 시간대에는 [대안]도 이용하실 수 있습니다.

Q: 예약이 필요한가요?
A: [평일/주말] 저녁은 예약을 권해드립니다. [전화번호]로 연락 주시면 됩니다.
   [n]인 이상 단체석도 준비되어 있습니다.

Q: 한국어로 응대가 되나요?
A: 네, 한국어와 영어 모두 응대해 드립니다.

Q: 포장/배달이 되나요?
A: 포장은 매장에서 바로 가능하고, 배달은 [플랫폼명]으로 주문하실 수 있습니다.

Q: 영업시간이 어떻게 되나요?
A: 평일 [시간], 주말 [시간]입니다. 공휴일은 프로필의 영업시간을 확인해 주세요.
```

## 업종별 추가 (해당하는 것만)

**음식점**
```
Q: 비건/채식 메뉴가 있나요?
Q: 아이와 함께 가도 되나요? (유아 의자 여부)
Q: 매운 정도를 조절할 수 있나요?
```

**뷰티**
```
Q: 예약 없이 방문해도 되나요?
Q: [시술명]은 시간이 얼마나 걸리나요?
Q: 어떤 제품을 사용하시나요?
```

**리테일**
```
Q: [특정 상품]을 취급하나요?
Q: 온라인 주문이나 배송이 되나요?
```

**교육**
```
Q: 무료 상담이나 레벨 테스트가 있나요?
Q: 수업은 몇 명 정원인가요?
Q: 성인반도 있나요?
```

## 등록 방법
GBP 프로필 → 지도/검색에서 내 업체 보기 → "질문하기" → 질문 등록 → 본인 계정으로 답변 작성 → 답변에 **👍(좋아요)** 를 눌러 상단 고정

## 주의
- 질문을 5~8개 이상 한 번에 몰아 올리지 않습니다. **2~3일 간격**으로 나눠 올리세요
- 실제로 자주 받는 질문만 올립니다. 억지 질문은 고객에게 어색하게 보입니다
