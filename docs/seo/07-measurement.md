# 07. 측정 체계 — 무엇을 보고 판단할 것인가

## 1. 도구 3종

| 도구 | 보는 것 | 주기 |
|---|---|---|
| **GBP 인사이트** | 프로필 조회, 검색어, 경로 요청, 통화, 웹 클릭 | 월 1회 |
| **Search Console** | 노출수, 클릭수, CTR, 평균 순위, 색인 상태, CWV | 월 1회 |
| **GA4** | 세션, 유입 경로, 전환(예약/주문/통화) | 월 1회 |

## 2. 월간 기록 항목 (`data/kpi-log.md`)

```markdown
## 2026-09
### GBP
- 프로필 조회(검색/지도): 000 / 000
- 검색어 유형: 브랜드 00% / 탐색형 00% / 직접 00%
- 액션: 경로요청 000, 통화 000, 웹클릭 000
- 리뷰: 총 00개(+00), 평균 0.0점, 답글률 00%
- 게시물: 0건

### Search Console
- 노출 0,000 / 클릭 000 / CTR 0.0% / 평균순위 0.0
- 색인 페이지: 00 / 00
- CWV: LCP 0.0s, INP 000ms, CLS 0.00

### 판단
- 잘된 것 / 안 된 것 / 다음 달 조정 1가지
```

## 3. 지표 해석 규칙

| 관찰 | 진짜 의미 | 조치 |
|---|---|---|
| 조회↑ 액션↓ | 노출은 되는데 **선택받지 못함** | 사진·리뷰·설명 품질 문제. 순위가 아니라 매력도 |
| 브랜드 검색만 많음 | 신규 발견이 안 됨 | 카테고리·서비스 항목·키워드 관련성 재점검 |
| 노출↑ 클릭↓ (GSC) | title/description CTR 문제 | 타이틀 재작성 |
| 순위는 올랐는데 방문 그대로 | 무관한 키워드로 잡히는 중 | 키워드맵 relevance 재조정 |
| 경로 요청↑ | **가장 좋은 신호** — 실제 방문 의도 | 유지 |

## 4. 판단 타임라인 — 조급함이 가장 큰 적

| 시점 | 판단 가능한 것 | 판단하면 안 되는 것 |
|---|---|---|
| 1~2주 | 세팅 완료 여부, 색인 여부 | 순위 (아직 반영 안 됨) |
| 4~6주 | 노출수 변화 추세 | 최종 성과 |
| 8~12주 | 순위·방문 변화, 전략 성패 | — |

**최소 12주는 같은 전략을 유지한다.** 4주마다 전략을 바꾸면 어느 것이 효과 있었는지 영원히 알 수 없다.

## 5. 순위 확인 방법 (정확하게)

1. **시크릿 창** 필수 (로그인 상태면 개인화로 실제보다 높게 보인다)
2. 브라우저 개발자도구 → Sensors → 위치를 우리 도시 좌표로 설정
3. Tier S 키워드 3개를 매월 같은 요일·같은 시간에 확인해 기록
4. 매장 기준 500m / 1km / 3km 지점을 각각 확인 — 거리에 따라 순위가 내려가는 것은 **정상 동작**이다
