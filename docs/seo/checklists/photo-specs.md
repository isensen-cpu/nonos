# ✅ 사진 규격·촬영 가이드 (스마트폰 기준)

## 1. 규격 (구글 기준)

| 항목 | 값 |
|---|---|
| 형식 | JPG 또는 PNG |
| 용량 | 10KB ~ 5MB |
| 최소 해상도 | 250 × 250 px |
| **권장 해상도** | **720 × 720 px 이상** |
| 금지 | 워터마크, 텍스트 삽입, 과도한 필터, 스톡 이미지 |

| 용도 | 비율 | 권장 크기 |
|---|---|---|
| 로고 | 1:1 | 720 × 720 |
| 커버 | 16:9 | 1024 × 576 |
| 일반 사진 | 4:3 또는 1:1 | 1200 × 900 이상 |

## 2. 필수 컷 리스트 (최소 20장)

| 종류 | 장수 | 촬영 포인트 |
|---|---|---|
| 로고 | 1 | 배경 여백 최소, 정사각형 크롭 |
| 커버 | 1 | 가장 대표적인 한 컷 (외관 또는 시그니처 메뉴) |
| **외관 - 낮** | 2 | 간판이 선명하게, 도로에서 보이는 시야 그대로 |
| **외관 - 밤** | 1 | 조명 켜진 상태. 저녁 손님이 찾을 때의 모습 |
| 입구/출입문 | 1 | "여기가 맞나?" 확신을 주는 컷 |
| 내부 전경 | 2 | 문 앞에서 안쪽으로, 넓어 보이게 |
| 좌석 | 2 | 2인석·단체석 각각 |
| 주차 공간 | 1 | 로컬 검색에서 의외로 강력 |
| 상품/메뉴 | 8+ | 대표 메뉴 각각 1장씩 |
| 사장/직원 | 2 | 얼굴이 나오면 신뢰 신호(E-E-A-T) |

## 3. 스마트폰 촬영 원칙 5가지

1. **자연광** — 낮 시간, 창가. 실내 조명만으로 찍으면 색이 누렇게 뜬다
2. **음식은 위에서 45도** — 접시 가장자리에 여백을 남긴다
3. **가로 촬영** — 세로는 지도에서 잘린다
4. **HDR 켜기 / 플래시 끄기** — 플래시는 음식 사진을 망친다
5. **한 컷을 3장씩** 찍고 가장 나은 것을 고른다

## 4. 파일명 규칙 (업로드 전 필수)

```
❌ IMG_1234.jpg, KakaoTalk_20260831.jpg
✅ portmoody-korean-restaurant-kimchi-jjigae-01.jpg
✅ 포트무디-한식당-외관-야간-01.jpg
```

형식: `[지역]-[업종]-[대상]-[번호].jpg` — 키워드는 하이픈(-)으로 연결, 공백·특수문자 금지

## 5. 업로드 전략

- 첫 주에 20장을 **한꺼번에 다 올리지 않는다**
- 초기 10장 → 이후 **주 2~3장씩 꾸준히**
- 이유: 최신성(freshness)도 신호다. 6개월간 새 사진이 없는 프로필은 활동성이 낮게 평가된다
- 계절/신메뉴가 바뀌면 즉시 갱신
