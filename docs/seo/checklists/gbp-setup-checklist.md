# ✅ 구글 비즈니스 프로필 세팅 체크리스트

> 인쇄해서 하나씩 지워가며 쓰는 용도. 상세 설명은 `docs/seo/05-google-maps-gbp.md`

## 1주차 — 관련성 (효과의 60%)

### 등록·인증
- [ ] 등록 유형 결정 (매장형 / 서비스 지역형 / 하이브리드)
- [ ] `business.google.com` 프로필 생성 또는 소유권 주장
- [ ] 소유권 확인 완료 (동영상 촬영 순서: 간판 → 거리 → 내부 → 장비 → 사업자증빙)

### 기본 정보
- [ ] 상호명 = 실제 간판과 100% 동일 (키워드 추가 ❌)
- [ ] 주소 우편번호까지 정확 / 지도 핀을 실제 출입구로 드래그
- [ ] 대표 전화번호 1개 (모든 채널에서 동일 표기)
- [ ] 웹사이트 URL + UTM (`?utm_source=google&utm_medium=organic&utm_campaign=gbp`)
- [ ] 정규 영업시간 + 브레이크타임
- [ ] 공휴일/특별 영업시간 미리 등록

### 관련성 신호
- [ ] **기본 카테고리 1개** 확정 (좁고 정확하게)
- [ ] 보조 카테고리 (실제 제공하는 것만, 최대 9개)
- [ ] 서비스/메뉴 항목 **10개 이상** 개별 등록 (이름+가격+300자 설명)
- [ ] 비즈니스 설명 750자 (첫 100자에 Tier S 키워드 + 도시명)
- [ ] 속성(Attributes) 뜨는 항목 전부 체크 (주차·배달·예약·결제·언어)
- [ ] 서비스 지역형인 경우: 서비스 지역 지정 (최대 20곳)

### 사진 (최소 20장)
- [ ] 로고 720×720 정사각형
- [ ] 커버 1024×576 (16:9)
- [ ] 외관 3장+ (낮/밤, 간판 보이게)
- [ ] 내부 5장+
- [ ] 상품/메뉴 8장+
- [ ] 팀/사장 2장+
- [ ] **모든 파일명을 `지역-업종-키워드-01.jpg` 형식으로 변경 후 업로드**
- [ ] 규격 확인: JPG/PNG, 10KB~5MB, 최소 250×250 (권장 720×720+), 워터마크·필터 ❌

### 리뷰 준비
- [ ] GBP에서 리뷰 요청 단축 링크 복사
- [ ] QR 코드 제작 → 계산대 스탠드 비치
- [ ] 영수증/포장 스티커에 QR 추가

---

## 1개월차 — 인지도 시작
- [ ] 게시물 주 1회 × 4회 (각각 사진 1장 + CTA 버튼 필수)
- [ ] Q&A 씨앗 질문 5개 등록 + 자체 답변
- [ ] 리뷰 10개 확보 (주 2~3개 페이스, 몰아받기 ❌)
- [ ] 리뷰 답글률 100% (1~2점은 24시간 내)
- [ ] NAP 인용 10곳 등록 (`nap-consistency.md`)
- [ ] 웹사이트에 LocalBusiness JSON-LD 적용
- [ ] Search Console 등록 + sitemap 제출
- [ ] 사진 주 2~3장 추가 업로드 지속

---

## 3개월차 — 성과 확인
- [ ] 리뷰 누적 30개+ / 평균 4.5점+
- [ ] 게시물 12회 누적
- [ ] 시크릿 창 + 위치 설정으로 Tier S 키워드 3개 순위 기록
- [ ] GBP 인사이트 KPI를 기준선과 비교 (`data/kpi-log.md`)
- [ ] GSC 검색어 CSV → 키워드맵 재실행
- [ ] 인접 지역 랜딩 페이지 제작 (그 지역 고유 정보를 담을 수 있을 때만)

## ⛔ 절대 하지 말 것

- [ ] 할인·사은품 걸고 리뷰 요청 → **리뷰 일괄 삭제**
- [ ] 가짜 리뷰 / 지인 대량 리뷰 → **필터링 + 신뢰도 하락**
- [ ] 운영하지 않는 주소·가상 오피스 등록 → **정지**
- [ ] 하루에 리뷰 몰아받기 → **스팸 판정**
