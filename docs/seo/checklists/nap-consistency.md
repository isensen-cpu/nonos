# ✅ NAP 일관성 점검표

> **N**ame / **A**ddress / **P**hone 이 모든 채널에서 **한 글자도 다르지 않아야** 구글이 같은 업체로 합산한다.
> `Port Moody` vs `Port Moody, BC` vs `포트무디` 혼용 = 신호가 3등분.

## 0. 표준 표기 확정 (여기를 복사해서 모든 곳에 붙여넣는다)

```
[Name]    (간판·사업자등록증과 동일하게 여기에 확정)
[Address] (우편번호 포함, 약어까지 통일: St / Street 중 하나로)
[Phone]   (국가번호 포함 형식 하나로: +1-604-000-0000)
```

**약어 통일 규칙 예시**: `#101` vs `Unit 101` vs `Suite 101` → 하나만. `Ave` vs `Avenue` → 하나만.

## 3. 점검 방법

1. 구글에 `"상호명" "전화번호"` 로 검색 → 나오는 모든 결과의 표기를 대조
2. 구글에 `"상호명" -site:내도메인` → 우리가 모르는 등록처 발견
3. 표기가 다른 곳을 발견하면 **수정 or 삭제** (중복 프로필은 반드시 삭제/병합)

## 4. 흔한 사고

| 사고 | 처리 |
|---|---|
| 중복 GBP 프로필이 존재 | 중복 신고 → 병합 요청 (방치하면 신호가 갈린다) |
| 이전 사업자의 프로필이 남아있음 | 소유권 주장 후 정보 갱신 |
| 전화번호를 여러 개 등록 | 대표 1개로 통일, 나머지는 부가 번호로 |
| 이사 후 옛 주소가 디렉토리에 잔존 | 전수 수정. 지도 신호가 두 곳으로 갈린다 |
