소상공인 로컬 검색 운영 체계

구글맵 상위노출 플레이북

검색량을 지어내지 않고, 순위를 조작하지 않고, 구글이 실제로 읽는 신호만 정확히 채워 로컬 검색에 잡히게 만드는 12주짜리 실행 체계입니다.

순위를 직접 바꾸는 API나 툴은 존재하지 않습니다. 우리가 하는 일은 구글이 읽는 신호를 정확하고 완전하게 채워, 알고리즘이 우리를 정답으로 고르게 만드는 것입니다.

웹 검색과 구글맵은 다른 알고리즘입니다. 소상공인은 구글맵 쪽 투자수익이 압도적으로 큽니다. 웹사이트가 없어도 로컬 팩 진입은 가능합니다.

효과는 4~12주 지연됩니다. 2주 만에 판단하면 반드시 잘못된 결정을 합니다.

01 — 알고리즘

구글맵 순위를 만드는 것은 세 가지뿐입니다

구글이 공식적으로 밝힌 로컬 랭킹 요소는 딱 세 개입니다. 전략은 여기서 자동으로 도출됩니다 — 통제 가능하면서 즉효인 것을 먼저 채웁니다.

관련성

즉효

검색어와 우리 프로필이 얼마나 정확히 맞는가. 카테고리·서비스 항목·설명·속성이 전부 여기에 들어갑니다.

2024년 이후 달라진 것 — 기획에 반드시 반영

  • Helpful Content가 코어 알고리즘에 통합되었습니다. 페이지 수를 늘리는 전략은 이제 역효과입니다. 적고 진짜 유용한 페이지가 이깁니다.
  • INP가 FID를 대체해 상호작용 반응성이 실측됩니다.
  • AI 개요가 상단을 차지하면서 정보성 키워드는 클릭이 나오지 않습니다. 반대로 "지금 가겠다/사겠다"는 로컬·거래 의도 키워드의 가치가 올랐습니다.

→ 블로그 물량전이 아니라 로컬 세팅에 집중하는 것이 지금 맞는 전략입니다.

02 — 키워드

무엇부터 할지를 숫자로 정합니다

감으로 키워드를 고르는 것이 소상공인 SEO 실패의 첫 번째 원인입니다. 실측 데이터를 넣으면 점수와 배치 위치가 나옵니다.

파이프라인

Google Keyword Planner (위치·언어 필터, 무료)
  ↓ CSV 내보내기
data/keywords/*.csv (가공하지 않고 그대로)
  ↓ npm run seo:score
점수화 = 검색량 × 의도 × (1−경쟁도) × 관련성
  ├→ Tier S·A  GBP 카테고리·설명·서비스 항목, 웹 타이틀
  ├→ Tier B    게시물 12주 로테이션, 블로그 롱테일
  └→ Tier C    보류 · Google Ads 후보

점수 계산기

플래너가 "100 – 1K" 같은 구간으로 준다면 하한값(100)을 넣습니다. 과대평가로 없는 수요에 투자하는 것을 막습니다.

내 데이터셋에서 가장 큰 검색량. 로그 정규화의 기준입니다.

한 페이지 = 한 개의 S/A 키워드. 한 페이지에 여러 개를 욱여넣으면 어느 것으로도 잡히지 않습니다.

03 — 구글맵 세팅

관련성을 1주 안에 100% 채웁니다

전체 작업량의 20%로 효과의 60%가 나오는 구간입니다. 웹사이트가 없어도 단독으로 실행할 수 있습니다.

카테고리 — 관련성 신호의 60%

기본 카테고리는 1개만 가능합니다. 넓은 것(Restaurant)보다 좁고 정확한 것(Korean Restaurant)이 유리합니다. 보조는 최대 9개, 실제 제공하는 것만 — 관련 없는 카테고리는 기본의 관련성을 희석시킵니다.

서비스·메뉴 항목 — 가장 저평가된 기능

각 항목이 검색 매칭 단위가 됩니다. 이름 + 가격 + 300자 설명으로 개별 등록하고, 최소 12개를 목표로 합니다. 복합 업종은 여기서 승부가 납니다.

비즈니스 설명 750자

첫 100자에 Tier S 키워드와 도시명을 넣습니다(검색결과에서 잘리는 지점). 키워드 나열은 금지 — 사람이 읽는 문장이어야 합니다. 가격·URL·이메일은 넣으면 반려됩니다.

사진 20장

JPG/PNG · 10KB~5MB · 권장 720×720 이상. 커버는 16:9. 외관은 낮/밤 각각. 파일명을 도시-업종-대상-01.jpg 영문으로 바꿔 올립니다 — 한글 파일명은 구글이 읽지 못합니다.

속성 · 영업시간

주차·배달·예약·결제수단·한국어 응대는 필터 검색 노출에 직결됩니다. 뜨는 항목은 전부 채웁니다. 공휴일 예외 영업시간도 미리 등록합니다.

Q&A 씨앗

고객을 기다리지 않습니다. 사장이 직접 질문을 올리고 직접 답변하는 것은 정책상 허용됩니다. 자주 받는 질문 5~8개를 2~3일 간격으로 등록합니다.

인지도 — 4~12주 누적

신호실행 기준
리뷰 확보 속도주 2~3개. 하루에 몰리면 스팸 필터에 걸립니다
답글률100%. 1~2점은 24시간 내, 방어하지 말고 사과 → 조치 → 오프라인 연락처
리뷰 최신성3개월 이상 공백은 감점 신호
리뷰 언어한국어·영어가 둘 다 있어야 양쪽 검색에 잡힙니다
게시물최소 주 1회. 사진 1장 + CTA 버튼 필수
NAP 인용10곳 이상, 한 글자도 다르지 않게
프로필 정지로 이어지는 것 — 절대 하지 않습니다
  • 상호명에 키워드 끼워넣기 — 실제 간판과 동일해야 합니다. 정지 또는 상호 강제 수정
  • 할인·사은품을 걸고 리뷰 요청 — 구글 리뷰 정책 위반, 리뷰 일괄 삭제
  • 가짜 리뷰 / 지인 대량 리뷰 — 필터링 + 프로필 신뢰도 하락
  • 운영하지 않는 주소·가상 오피스 등록 — 정지
  • 지역명만 바꾼 복제 페이지 대량 생산 — Helpful Content 신호로 사이트 전체 하락
04 — 복합 업종

업종이 여럿이면 정체성을 하나로 잡습니다

구글은 하나의 사업장을 하나의 정체성으로 이해합니다. 음식·뷰티·리테일·교육을 동등하게 걸면 관련성이 4등분되어 어느 것으로도 상위에 잡히지 않습니다.

결정 순서

Q1. 지난 3개월 매출에서 가장 큰 업종은?
  ↓
그 업종의 가장 좁고 정확한 카테고리 1개 = 기본 카테고리
  ↓
Q2. 나머지 업종은?
  ├→ 각 업종의 카테고리를 보조로 등록 (합쳐 최대 9개)
  ├→ 각 업종의 상품을 서비스 항목으로 개별 등록 ← 진짜 승부처
  └→ 각 업종을 게시물 로테이션에 배치

프로필을 나눠도 되는 경우

아래 두 조건을 모두 충족할 때만 별도 프로필이 허용됩니다.

  • 법적으로 별개 사업자이고 (별도 사업자등록·별도 상호)
  • 물리적으로 구분된 출입구·공간을 쓰며, 각각 전용 직원이 상주

한 공간에서 사장 한 명이 여러 업종을 운영한다면 프로필은 하나입니다. 나누면 중복 프로필로 정지됩니다.

05 — 실행 순서

웹사이트 없이 12주

순서에는 이유가 있습니다. 앞 단계의 산출물이 뒤 단계의 입력이 되고, 효과가 큰 것이 앞에 있습니다.

0주차 · 준비

프로필 · 씨앗 키워드 · 촬영 계획

사업장 정보를 입력하고 씨앗 키워드를 뽑습니다. 구글 광고 계정(무료)을 만들고 KPI 기준선을 기록합니다. 기준선을 남기지 않으면 3개월 뒤 성과를 증명할 수 없습니다.

1주차 · 실측 + 등록

키워드 플래너 CSV → 우선순위표, 그리고 소유권 확인

플래너에서 지역·언어를 맞춰 조회하고 CSV를 받습니다. 동시에 프로필을 등록하고 소유권 확인 동영상을 촬영합니다 — 간판 → 주변 거리 → 출입구 → 내부 → 영업 도구 → 사업자 증빙을 끊김 없이 한 번에.

2주차 · 관련성

승인 당일에 몰아서 세팅

승인까지 3~7일. 기다리는 동안 설명·서비스 항목 문구를 미리 씁니다. 승인 나면 카테고리·설명·서비스 12개·속성·사진·Q&A를 한 번에 끝냅니다. 여기까지가 전체 효과의 60%입니다.

3~8주차 · 콘텐츠

게시물 주 1회, 사진 주 2~3장

12주 로테이션 캘린더대로 돌립니다. 한 번에 몰아 올리지 않습니다 — 최신성 자체가 신호입니다.

4~12주차 · 인지도

리뷰 30개, NAP 인용 10곳

결제 직후 QR로 요청 동선을 물리적으로 만듭니다. 부탁에 의존하지 않습니다. 답글은 100%.

12주차 · 판단

기준선과 비교하고, 그때 웹사이트를 결정

GBP 인사이트에서 "웹사이트 클릭" 수요가 실제로 보일 때 만드는 것이 순서입니다. 지금 만들면 관리 대상만 늘어납니다.

지표 해석 — 숫자가 말하는 것

관찰진짜 의미조치
조회↑ 액션↓노출은 되는데 선택받지 못함사진·리뷰·설명 품질. 순위가 아니라 매력도 문제
브랜드 검색만 많음신규 발견이 안 됨카테고리·서비스 항목 재점검
순위↑ 방문 그대로무관한 키워드로 잡히는 중키워드맵 관련성 재조정
경로 요청↑가장 좋은 신호 — 실제 방문 의도유지

순위 확인은 반드시 시크릿 창에서, 위치를 우리 도시로 설정하고 합니다. 로그인 상태로 보면 개인화 때문에 실제보다 높게 보입니다. 매장 기준 거리에 따라 순위가 내려가는 것은 정상 동작입니다.
