# 05. 구글맵 상위노출 세팅 (Google Business Profile)

> 소상공인 SEO에서 **투입 대비 효과가 가장 큰 작업**. 웹사이트가 없어도 단독으로 실행 가능하며, 1~2주 안에 100% 완료할 수 있다.
> 이 문서는 00번 문서의 로컬 3요소(**관련성 / 거리 / 인지도**)를 그대로 실행 항목으로 옮긴 것이다.

---

## STEP 0. 등록 유형 결정 (가장 먼저)

| 유형 | 조건 | 설정 |
|---|---|---|
| **매장형** | 고객이 찾아오는 실제 주소가 있음 | 주소 공개. 지도 핀이 순위의 기준점 |
| **서비스 지역형(SAB)** | 출장/방문 서비스, 고객이 오지 않음 | **주소 숨김** + 서비스 지역 최대 20곳 지정 |
| **하이브리드** | 매장 + 배달/출장 병행 | 주소 공개 + 서비스 지역 함께 지정 |

> 서비스 지역형인데 주소를 공개하면 정지 사유가 될 수 있다. 반대로 매장형인데 주소를 숨기면 "거리" 신호를 스스로 버리는 것이다.

---

## STEP 1. 소유권 확인 (Verification)

1. `business.google.com` → 비즈니스 검색 → 이미 존재하면 **소유권 주장**, 없으면 신규 등록
2. 확인 방법: 우편엽서 / 전화 / 이메일 / **동영상 확인**(최근 가장 흔함)
3. 동영상 확인 준비물 — 한 번에 끊김 없이 촬영해야 한다:
   - 간판(상호가 보이게) → 주변 거리(위치 확인 가능하게) → 매장 내부 → 영업 도구(주방/장비/POS) → 사업자 증빙(사업자등록증, 라이선스)

**실패 시 재신청까지 시간이 오래 걸리므로, 촬영 전 위 순서를 한 번 연습하고 찍는다.**

---

## STEP 2. 관련성 세팅 — *1주차에 100% 채운다 (즉효)*

### 2-1. 상호명 (Name) — 절대 규칙
- 실제 간판·사업자등록증과 **완전히 동일하게**
- ❌ `OO식당 | 밴쿠버 1등 한식 맛집` → 키워드 스터핑, 정지 또는 강제 수정
- ✅ `OO식당` / `OO Korean Restaurant`
- 한/영 병기는 실제 간판에 병기되어 있을 때만

### 2-2. 카테고리 — 관련성 신호의 60%
| 구분 | 개수 | 원칙 |
|---|---|---|
| **기본 카테고리** | **1개만** | 매출의 핵심을 가장 정확히 설명하는 것. 넓은 것(`Restaurant`)보다 **좁고 정확한 것**(`Korean Restaurant`)이 유리하다 |
| 보조 카테고리 | 최대 9개 | **실제로 제공하는 것만.** 관련 없는 것을 걸면 기본 카테고리의 관련성이 희석된다 |

> 카테고리는 구글이 정한 목록에서만 고를 수 있다(직접 입력 불가). 검색창에 업종 영문명을 쳐서 후보를 확인한다.
> 판단 기준: **"이 카테고리로 검색한 사람이 우리 가게에 와서 만족할까?"** 아니면 빼라.

### 2-3. 서비스 / 메뉴 항목 — 가장 저평가된 기능
- 제공 서비스를 **개별 항목으로 하나씩** 등록한다. 각 항목이 검색 매칭 단위가 된다.
- 각 항목에 이름 + 가격(가능하면) + **300자 설명**. 설명에 Tier A 키워드를 자연스럽게 넣는다.
- 음식점은 메뉴 항목을, 뷰티/의료는 시술명을, 교육은 과목·레벨을 등록.
- **최소 10개 이상** 등록을 목표로 한다.

### 2-4. 비즈니스 설명 (750자)
구조: `[핵심 키워드 + 지역명] → [차별점] → [주요 서비스 3가지] → [이용 안내]`

작성 규칙:
- **첫 100자에 Tier S 키워드와 도시명**을 넣는다 (검색결과에서 잘리는 지점)
- 키워드 나열 금지. 사람이 읽는 문장이어야 한다
- 가격·프로모션·URL은 넣지 않는다 (정책 위반으로 반려됨)

```
예시 골격)
"포트무디에 위치한 한식당 OO식당은 매일 직접 담그는 김치와 24시간 우린 사골 육수로
정통 한식을 제공합니다. 김치찌개, 불고기, 한식 BBQ를 중심으로 점심 특선과 포장·배달을
운영하며, 4인 이상 단체 예약과 케이터링도 가능합니다. 주차 공간이 있으며 영어·한국어
모두 응대해 드립니다."
```

### 2-5. 속성 (Attributes) — 필터 검색 노출에 직결
업종별로 뜨는 항목이 다르다. **뜨는 것은 전부 채운다.**
- 편의: 주차, 무료 와이파이, 화장실, 휠체어 접근
- 서비스: 매장 식사 / 포장 / 배달 / 예약 / 온라인 주문
- 결제: 카드, 모바일 결제, 현금
- 대상: 가족 친화, 반려동물 동반, 단체석
- 언어: 한국어 응대 ← **교민 상권에서 강력한 필터 신호**

### 2-6. 영업시간
- 정규 영업시간 + **공휴일/특별 영업시간**을 미리 등록
- 브레이크타임이 있으면 시간대를 분리 등록
- **"영업 중" 여부는 검색 필터(open now)에 직접 쓰인다.** 부정확하면 노출도 잃고 리뷰도 잃는다.

### 2-7. 사진 — 최소 20장
| 종류 | 규격 | 장수 | 팁 |
|---|---|---|---|
| 로고 | 720×720px, 정사각형 | 1 | 배경 여백 최소화 |
| 커버 | 1024×576px, **16:9** | 1 | 가장 대표적인 한 컷 |
| 외관 | 720×720px 이상 | 3+ | **낮/밤 각각**, 간판이 보이게, 찾아오는 시점의 시야 |
| 내부 | 720×720px 이상 | 5+ | 좌석, 전체 분위기, 청결함 |
| 상품/메뉴 | 720×720px 이상 | 8+ | 자연광, 위에서 45도, 접시 가장자리 여백 |
| 팀/사장 | 720×720px 이상 | 2+ | 신뢰 신호 (E-E-A-T) |

**공통 규격**: JPG 또는 PNG / 10KB~5MB / 최소 250×250px, 권장 720×720px 이상 / 필터·워터마크·텍스트 삽입 금지(스톡 이미지 금지)

**파일명 규칙** — 업로드 전 반드시 변경 (`IMG_1234.jpg` ❌)
```
portmoody-korean-restaurant-kimchi-jjigae-01.jpg
포트무디-한식당-김치찌개-01.jpg
```

**업로드 주기**: 한 번에 다 올리지 말고 **주 2~3장씩 꾸준히**. 최신성도 신호다.

### 2-8. Q&A — 직접 씨앗을 심는다
고객이 질문할 때까지 기다리지 않는다. **사장이 직접 질문을 올리고 직접 답변**할 수 있다(정책상 허용).
자주 받는 질문 5~8개를 미리 등록하되, 질문·답변에 Tier B 키워드를 자연스럽게 포함한다.
```
Q: 포트무디 매장에 주차 가능한가요?
A: 네, 건물 앞 무료 주차 6대가 가능하며 저녁 시간대에는 옆 공영주차장도 이용하실 수 있습니다.
```

## STEP 3. 거리 신호 — *고정값, 관리만*

- 주소는 **우편번호까지 정확히**. 지도 핀 위치를 직접 드래그해 실제 출입구에 맞춘다(핀이 건물 뒤편에 찍히면 경로 안내가 어긋나 이탈이 발생한다).
- 인접 상권은 주소로 잡을 수 없다 → **게시물·서비스 지역·웹 콘텐츠**로 커버한다.
- 서비스 지역형은 지역을 **최대 20곳**까지, 실제 출장 가능한 곳만 지정한다.

---

## STEP 4. 인지도 세팅 — *4~12주 누적, 장기전*

### 4-1. 리뷰 전략
**요청 타이밍 (전환율 순)**
1. 결제 직후, 고객 만족도가 최고점일 때 — 테이블/카운터 **QR 스탠드**
2. 서비스 완료 24시간 내 문자/카톡 1회
3. 재방문 고객에게 대면 요청

**리뷰 링크 만들기**: GBP 관리 화면 → "리뷰 요청" → 단축 링크 복사 → QR 코드로 변환해 인쇄

**요청 문구 예시**
```
오늘 식사 어떠셨나요? 구글 리뷰에 한 줄 남겨주시면 큰 힘이 됩니다 🙏
(QR) → 30초면 됩니다
```

**⚠️ 절대 금지**: 할인·사은품·이벤트 응모 등 **대가를 걸고 리뷰를 요청하면 구글 정책 위반**이다. 리뷰가 일괄 삭제되고 프로필 신뢰도가 떨어진다.

**답글 규칙 — 100% 답글을 단다**
| 평점 | 답글 원칙 |
|---|---|
| 4~5점 | 24시간 내. 감사 + **메뉴명/서비스명(키워드)을 자연스럽게 언급** |
| 3점 | 개선 의지 + 구체적 조치 |
| 1~2점 | **24시간 내, 방어하지 말고** 사과 → 사실 확인 → 오프라인 연락처 제시. 다른 예비 고객이 읽는다는 것을 잊지 않는다 |

**페이스**: 주 2~3개. 하루에 20개가 몰리면 스팸 필터에 걸린다.

### 4-2. 게시물 (Posts) — 최소 주 1회
게시물은 **최신성 + 추가 키워드 표면** 두 가지를 동시에 준다.

| 유형 | 용도 | CTA 버튼 |
|---|---|---|
| 업데이트 | 신메뉴, 일상, 재료 소개 | 자세히 보기 |
| 이벤트 | 기간 한정 행사 | 자세히 보기 |
| 혜택 | 프로모션 | 온라인 주문 / 예약 |
| 제품 | 개별 상품 | 구매 |

작성 규칙: 첫 문장에 Tier B 키워드 1개 + 사진 1장 필수 + CTA 버튼 반드시 설정.
**첫 4주 스케줄 예시**
| 주차 | 주제 | 키워드 |
|---|---|---|
| 1주 | 대표 메뉴 소개 | Tier S 키워드 |
| 2주 | 매장/공간 소개 (주차·좌석) | 지역명 + 편의 |
| 3주 | 재료·조리 과정 (신뢰) | 차별점 키워드 |
| 4주 | 이용 안내 (포장·예약·단체) | transactional 키워드 |

### 4-3. 인용(Citation) — NAP 동일 표기로 등록
아래에 **한 글자도 다르지 않게** 등록한다.
- 자사 웹사이트 (푸터 + 연락처 페이지, JSON-LD 포함 → 07번 문서)
- 인스타그램/페이스북 프로필
- Yelp, Apple Maps, Bing Places
- 지역 상공회의소, 한인회, 지역 커뮤니티 디렉토리
- 배달앱, 예약 플랫폼

점검표: `docs/seo/checklists/nap-consistency.md`

### 4-4. 웹사이트 연결
GBP의 웹사이트 필드는 반드시 채운다. **연결된 웹사이트의 SEO 점수가 로컬 인지도에 반영**된다.
- 홈이 아니라 **지역 랜딩 페이지**로 연결하는 것이 전환율이 높다
- UTM 파라미터로 유입 측정: `?utm_source=google&utm_medium=organic&utm_campaign=gbp`

## STEP 5. 검증 — "제대로 세팅됐나?" 확인법

| 확인 | 방법 | 합격 기준 |
|---|---|---|
| 프로필 완성도 | GBP 관리 화면 상단 | 100% (미완료 항목 0) |
| 실제 노출 | 시크릿 창 + 위치를 우리 도시로 설정 → Tier S 키워드 검색 | 로컬 팩(지도 3개) 안에 등장 |
| 위치별 순위 차이 | 매장에서 500m/1km/3km 떨어진 지점에서 각각 검색 | 거리에 따라 순위가 떨어지는 것은 **정상** |
| 어떤 검색어로 찾아왔나 | GBP 인사이트 → 검색어 | 비브랜드 키워드 비중 60%+ |
| NAP 일치 | 구글에 `"상호명" "전화번호"` 로 검색 | 표기가 갈리는 곳 0곳 |

> ⚠️ 로그인한 내 계정으로 검색하면 개인화 때문에 순위가 실제보다 높게 보인다. **반드시 시크릿 창**에서 확인한다.

## STEP 6. 우선순위 실행 순서

**1주차 (즉효 — 여기까지가 전체 효과의 60%)**
- [ ] 소유권 확인 완료
- [ ] 기본 카테고리 1개 + 보조 카테고리 확정
- [ ] 비즈니스 설명 750자 작성
- [ ] 영업시간 + 속성 전부 채우기
- [ ] 사진 20장 (파일명 규칙 적용)
- [ ] 서비스/메뉴 10개 이상 등록
- [ ] 리뷰 요청 QR 제작·비치

**1개월차**
- [ ] 게시물 주 1회 × 4회
- [ ] Q&A 5개 등록
- [ ] 리뷰 10개 확보 + 100% 답글
- [ ] NAP 인용 10곳 등록
- [ ] 웹사이트 연결 + JSON-LD 적용

**3개월차**
- [ ] 리뷰 누적 30개 이상, 평점 4.5+
- [ ] 게시물 12회 누적
- [ ] GBP 인사이트로 KPI 비교 → 키워드맵 갱신
- [ ] 인접 지역 랜딩 페이지 제작

전체 체크리스트: `docs/seo/checklists/gbp-setup-checklist.md`
