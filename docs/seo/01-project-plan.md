# 01. 프로젝트 기획서 — 무엇을 어떤 순서로 만들 것인가

## 1. 문제 정의

소상공인이 SEO에서 실패하는 지점은 "지식 부족"이 아니라 **운영 체계의 부재**다.

| 흔한 실패 | 원인 | 이 프로젝트의 해법 |
|---|---|---|
| 감으로 키워드를 고른다 | 실측 데이터 없음 | Keyword Planner 실측 CSV → 점수화 자동 산출 |
| 어디에 뭘 써야 할지 모른다 | 키워드-배치 매핑 없음 | 키워드맵이 채널·배치 위치까지 지정 |
| 세팅하다 만다 | 할 일 목록이 없음 | 1주/1개월/3개월 3단계 체크리스트 |
| 효과를 모른다 | 측정 기준 없음 | GBP 인사이트 + GSC 고정 KPI 세트 |
| 한 번 하고 끝난다 | 반복 루틴 없음 | 주간/월간 운영 캘린더 |

## 2. 목표와 KPI

**북극성 지표: 구글을 통한 실제 방문/문의 수** (순위 그 자체가 아니다.)

### 로컬(구글맵) KPI — GBP 인사이트에서 측정
| 지표 | 3개월 목표(기준선 대비) |
|---|---|
| 프로필 조회수 (검색+지도) | +100% |
| 검색어 중 "탐색형(비브랜드)" 비중 | 60% 이상 |
| 경로 요청 수 | +80% |
| 통화 클릭 수 | +50% |
| 리뷰 총 개수 | +30개 (주 2~3개 페이스) |
| 평균 평점 | 4.5 이상 유지 |

### 웹 KPI — Search Console에서 측정
| 지표 | 3개월 목표 |
|---|---|
| 색인된 페이지 | 목표 페이지 100% |
| 노출수(Impressions) | +150% |
| 평균 게재순위 | 타깃 키워드 20위 → 10위 이내 |
| Core Web Vitals | 3지표 모두 "양호" |

> **기준선(baseline)을 먼저 기록한다.** 시작일의 수치를 `data/kpi-baseline.md`에 적지 않으면 3개월 뒤 성과를 증명할 수 없다.

## 3. 범위 (Scope)

### 포함
- 키워드 리서치 파이프라인 (수집 → 점수화 → 우선순위 → 채널 배분)
- 구글 비즈니스 프로필(GBP) / 구글맵 상위노출 세팅
- 웹사이트 기술 SEO 기준 세팅 (Next.js 기반 템플릿)
- 콘텐츠·리뷰 운영 루틴
- 측정 체계

### 제외 (명시적으로 하지 않음)
- 순위 자동 조작, 리뷰 매크로, 링크 구매 → **금지 행위, 정지 리스크**
- 유료광고(Google Ads) 집행 → 키워드맵에 Ads 채널 배분까지만 제공. 실제 집행은 별도 의사결정
- 네이버 SEO → 구조가 완전히 다름. 필요 시 별도 프로젝트

## 4. 기획 시 반드시 정해야 하는 6가지 (미정이면 진행 불가)

1. **비즈니스 유형** — 매장형(주소 공개) / 서비스 지역형(출장, 주소 비공개) / 하이브리드
   → 이게 GBP 등록 방식과 "거리" 신호 전략을 통째로 바꾼다.
2. **정확한 NAP** — 간판과 100% 동일한 상호, 우편번호까지 포함한 주소, 대표 번호 1개
3. **기본 카테고리 1개** — 매출의 핵심. 여러 개를 기본으로 걸 수 없다.
4. **타깃 고객의 언어 비중** — 한국어 위주 / 영어(현지) 위주 / 혼합
   → 키워드 우선순위와 프로필 표기 순서가 여기서 갈린다.
5. **핵심 지역명 3개** — 우리 주소 도시 1 + 인접 상권 2
6. **주간 투입 가능 시간** — 소상공인 현실 기준 주 2시간을 가정해 계획을 짠다. 이보다 적으면 범위를 줄인다.

## 5. 로드맵 (12주)

| 단계 | 기간 | 산출물 | 성공 기준 |
|---|---|---|---|
| **P0. 준비** | 0주차 | `business.profile.json`, KPI 기준선 | 위 6가지 확정 |
| **P1. 키워드** | 1주차 | `keyword-map.md/csv/json` | 실측 키워드 30개 이상 점수화 |
| **P2. 로컬 세팅** | 1~2주차 | GBP 100% 완성 | 프로필 완성도 100%, 사진 20장, 서비스 등록 완료 |
| **P3. 기술 SEO** | 2~3주차 | metadata / sitemap / robots / JSON-LD | GSC 색인 완료, CWV 양호 |
| **P4. 콘텐츠** | 3~8주차 | 게시물 주 1회, 랜딩 페이지 | 타깃 키워드 페이지 100% 커버 |
| **P5. 인지도** | 4~12주차 | 리뷰 확보, 인용(citation) 등록 | 리뷰 +30, 디렉토리 10곳 NAP 일치 |
| **P6. 측정·개선** | 매월 | 월간 리포트 | KPI 달성률 확인 → 키워드맵 재조정 |

> **P2가 가장 ROI가 높다.** 총 작업량의 20%로 효과의 60%가 나온다. 웹사이트가 아직 없어도 P2는 단독 실행 가능하다.

## 6. 데이터 파이프라인

```
 Google Keyword Planner (지역·언어 필터)
        │  CSV export
        ▼
 data/keywords/*.csv
        │  node tools/seo/score-keywords.mjs
        ▼
 점수화 = 검색량 × 검색의도 × (1-경쟁도) × 관련성
        │
        ├─→ Tier S/A  →  GBP 설명·카테고리·서비스명, 웹 메인/랜딩 타이틀
        ├─→ Tier B    →  GBP 게시물, 블로그 롱테일
        └─→ Tier C    →  Google Ads 후보 / 보류
```

## 7. 산출물 목록

| 파일 | 용도 |
|---|---|
| `data/business.profile.json` | 사업장 단일 진실 원천(NAP·카테고리·서비스·지역) — 모든 문서/코드가 여기를 참조 |
| `data/keywords/output/keyword-map.*` | 우선순위 키워드맵 (md/csv/json) |
| `docs/seo/05-google-maps-gbp.md` | 구글맵 상위노출 세팅 실행서 |
| `docs/seo/checklists/*` | 즉시 실행 체크리스트 4종 |
| `templates/next-seo/*` | Next.js 기술 SEO 코드 템플릿 |

## 8. 리스크와 대응

| 리스크 | 확률 | 대응 |
|---|---|---|
| Keyword Planner가 검색량을 구간("100~1천")으로만 보여줌 | 높음 | 구간 하한값으로 보수적 점수화(툴에 내장). Search Console 실측으로 3개월 뒤 보정 |
| 리뷰가 안 모임 | 높음 | 결제 직후 QR 요청 동선 설계. 대가 제공 금지 |
| 사진·콘텐츠 제작 리소스 부족 | 중간 | 스마트폰 촬영 규격 가이드 제공, 주 1회로 부하 고정 |
| 상호에 키워드를 넣고 싶은 유혹 | 중간 | 정지 리스크 문서화 (00번 문서 4장) |
| 3개월간 변화 없음 | 낮음 | P2 완성도부터 재점검 — 대부분 카테고리/서비스 미등록이 원인 |
