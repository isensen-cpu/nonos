# 06. 콘텐츠·리뷰 운영 루틴 (주 2시간 기준)

> SEO 실패의 대부분은 지식이 아니라 **지속 실패**다. 부하를 고정해 굴러가게 만든다.

## 1. 주간 루틴 (총 60분)

| 요일 | 작업 | 시간 |
|---|---|---|
| 월 | GBP 게시물 1건 (Tier B 키워드 1개 + 사진 1장 + CTA) | 15분 |
| 수 | 사진 2~3장 업로드 (파일명 규칙 적용) | 10분 |
| 금 | 새 리뷰 전체 답글 + 리뷰 요청 QR 비치 확인 | 15분 |
| 금 | Q&A 확인, 신규 질문 답변 | 10분 |
| 금 | 영업시간/공휴일 예외 등록 확인 | 10분 |

## 2. 월간 루틴 (총 90분)

| 작업 | 내용 | 시간 |
|---|---|---|
| KPI 기록 | GBP 인사이트 + GSC 수치를 `data/kpi-log.md`에 기록 | 20분 |
| 키워드맵 갱신 | GSC 검색어 CSV 추가 → `score-keywords.mjs` 재실행 | 20분 |
| 콘텐츠 1건 | Tier B 롱테일 블로그/랜딩 1개 | 40분 |
| NAP 점검 | 신규 등록 채널 표기 확인 | 10분 |

## 3. 게시물 소재 12개 (3개월치)

| # | 소재 | 매핑 |
|---|---|---|
| 1 | 대표 메뉴/서비스 소개 | Tier S |
| 2 | 매장 공간·주차 안내 | 지역명 + 편의 |
| 3 | 재료/제품 원산지·품질 | 차별점 |
| 4 | 사장/직원 소개 | E-E-A-T |
| 5 | 이용 안내 (포장·예약·단체) | transactional |
| 6 | 계절 한정 메뉴 | 계절 키워드 |
| 7 | 고객 후기 재소개 (동의 후) | 신뢰 |
| 8 | 자주 받는 질문 1개 심화 | 롱테일 |
| 9 | 인접 지역 고객 대상 안내 | 인접 도시명 |
| 10 | 제작/조리 과정 | 차별점 |
| 11 | 신규 서비스/메뉴 출시 | 신규 키워드 |
| 12 | 이벤트/기념일 | 시즌 |

## 4. 리뷰 운영

**요청 동선을 물리적으로 만든다** — 부탁하는 것에 의존하지 않는다.
- 계산대 QR 스탠드 (고정)
- 영수증·포장 스티커에 QR
- 서비스 완료 24시간 내 문자 1회 (2회 이상 ❌)

**답글 템플릿**
```
[5점] ○○님, 김치찌개 맛있게 드셨다니 정말 기쁩니다! 다음에 오시면
      새로 나온 보쌈도 추천드릴게요. 포트무디에서 또 뵙겠습니다 :)
      → 감사 + 메뉴명(키워드) + 재방문 유도

[1~2점] 불편을 드려 죄송합니다. 말씀 주신 대기 시간 문제는 직원 배치를
        조정해 개선하고 있습니다. 괜찮으시면 604-000-0000으로 연락 주시면
        직접 확인하고 싶습니다.
        → 사과 + 구체적 조치 + 오프라인 연락처 (변명·반박 금지)
```

**⚠️ 대가를 제공한 리뷰 요청은 구글 정책 위반**이며 리뷰 일괄 삭제로 이어진다.

## 5. 하지 말아야 할 콘텐츠

| 금지 | 이유 |
|---|---|
| 지역명만 바꾼 복제 페이지 대량 생산 | Helpful Content 신호 → 사이트 전체 하락 |
| AI로 뽑아 그대로 올린 정보성 글 | 경험(Experience) 신호 없음 + AI 개요에 클릭을 뺏김 |
| 키워드 나열식 문장 | 스팸 판정 |
| 남의 사진/스톡 이미지 | 로컬 신뢰 신호 상실, 저작권 리스크 |

**대체 원칙**: 우리만 쓸 수 있는 것을 쓴다 — 실제 조리 과정, 실제 고객 사례, 실제 매장 사진, 우리 동네 정보.
